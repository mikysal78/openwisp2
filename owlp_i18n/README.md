# Traduzioni custom WiFi Login Pages (i18n)

Directory opzionale: metti qui eventuali file di traduzione custom
(es. `it.json` / `en.json` personalizzati) che il ruolo copia in
`<wifi-login-pages>/i18n` prima della build.

Se vuota, vengono usate le traduzioni di default di
openwisp-wifi-login-pages.
