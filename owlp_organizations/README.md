# Configurazione organizzazioni WiFi Login Pages

Metti in questa directory un file YAML per ogni organizzazione
(es. `default.yml`), con la configurazione delle login pages
(slug, UUID e token RADIUS dell'organizzazione, testi, loghi, ecc.).

UUID e token li trovi in OpenWISP:
**admin → Organizations → (la tua org) → Organization RADIUS settings**.

Formato e opzioni disponibili:
https://github.com/openwisp/ansible-openwisp-wifi-login-pages#organization-configuration
https://github.com/openwisp/openwisp-wifi-login-pages#add-organization-configuration
